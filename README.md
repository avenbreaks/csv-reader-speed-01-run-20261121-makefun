A fast drop-in for csv-reader 1.0.0: reads broken CSV files exactly as csv-reader does — quoted fields, doubled quotes, embedded line breaks, stray CRs, quote junk, unterminated quotes, short and long rows with errors — in a single left-to-right pass, about 2x faster end to end on the practice set.

## Run it

```sh
MAKEFUN_INPUT_DIR=./input MAKEFUN_OUTPUT_DIR=./output node main.ts
```
